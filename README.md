# Sepo Legal Practitioners

A static one-page site for Sepo Legal Practitioners, a Lusaka firm of advocates, notaries and commissioners for oaths.

## Preview locally

```bash
python3 -m http.server 4174
```

Open `http://127.0.0.1:4174/`.

## Structure

- `index.html` — content
- `styles.css` — layout
- `script.js` — navigation, reveals, English / Nyanja / Bemba
- `assets/logo-mark.png` — official mark
- `assets/people/` — standardised portraits

Intended domain: `sepolegal.com`. Host as a Digital Ocean App Platform static site via `.do/app.yaml`.
